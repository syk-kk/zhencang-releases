# 帧藏 · ZhenCang

**把散落在硬盘里的影像，收进一座只属于你的本地媒体库。**

帧藏是一款本地优先的 Windows 本地媒体库：扫描本机目录，自动归集作品，提供瀑布流浏览、中文全文搜索、收藏评分、智能合集、演员与标签、每日帧藏、数据统计，以及可选的 AI 助手。

所有数据库、缩略图、日志、知识与记忆都留在本机。没有遥测，没有后台上传。

## 下载

[**下载最新版本 →**](https://github.com/syk-kk/zhencang-releases/releases/latest)

- 系统要求：Windows 10/11 x64
- 覆盖安装会保留安装目录下的 `data/`

## 亮点

- 多路径扫描、增量扫描、断点续扫、多分集归集、蓝光原盘识别
- 瀑布流首页、详情画廊、中文全文搜索、收藏评分、智能合集
- 演员与标签、查重、批量整理、数据统计、每日帧藏
- 可选 AI 助手：自然语言找片与整理、知识库、长期记忆、生图、内置浏览器
- 本地优先，无遥测；AI 支持 OpenAI 兼容 / Ollama / LM Studio

## 系统要求

Windows 10/11 x64
